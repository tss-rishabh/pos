# Legacy oracle golden inventory

Every place the repository ran a Python, Go, PHP, Docker or `run*.sh` legacy oracle,
and what replaced it. Captured outputs live beside this file as
`<area>/<case>.json` and are read through `load.ts` (backend) or
`frontend/tests/golden/load.ts` (frontend). Each file records `sourceCommit`,
`oracle`, `runtime`, `capturedAt`, the originating `test`, and one entry per
distinct invocation keyed by `inputSha256` (SHA-256 of the exact stdin bytes,
after any documented placeholder substitution) plus the logical args.

Capture environment (19 November 2026, outside the repository):

- Legacy POS web: `backend-pos-web` 78d5b63d6a149a6bf2c748fa1d191799c59ecb8a. The
  working checkout HEAD 62d6ce1 differs from the pin only in docs/agent tooling
  (`git diff --stat 78d5b63 HEAD` touches no application file); oracles that
  require `git rev-parse HEAD == pin` used a shared clone detached at the pin.
- API v2: `backend-tss-api_v2` 2960acbea10c4eaf16b6d99e15ff6e03ef7724c5 (the pin in
  `compatibility/upstream/README.md`), extracted with `git archive` and passed as
  `POS_LEGACY_IMPORT_SOURCE_ROOT`; goldens from these oracles record that commit.
- `python3`/`python` resolved to CPython 3.10.22 (the source Dockerfiles' runtime; r9
  showed 3.14 float sums differ). `uv run --no-project` oracles were pinned to 3.10.22;
  `uv --frozen --project` oracles and the existing `.venv` oracles used the
  interpreter their lock/venv pins (3.12.15 or 3.10.22), as recorded in `runtime`.
- Every capture was taken by running the unchanged test with a recording wrapper
  around `node:child_process`; deterministic cases were captured twice and compared.
- No production database, credential or live service was used. MySQL-backed tests ran
  against the local isolated fixture server with per-run schemas.

Status values: **captured** (test rewired to the golden, assertions unchanged);
**uncaptured** (oracle kept, reason given; no values invented); **obsolete**
(exercises code removed by the 18–19 Nov decisions, left for W2); **not-oracle**
(the spawn is not a legacy oracle runtime).
